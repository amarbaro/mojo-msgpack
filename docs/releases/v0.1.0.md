# mojo-msgpack v0.1.0

**Released:** 2026-11-04 · **Commit:** `0ab9971` · **Previous:** first release

## What it does

MessagePack for Mojo 1.2: an `Encoder` byte-identical to Python `msgpack.packb(use_bin_type=True)`, and
`parse(data)` into a flat preorder node table (`Doc`) that raises on any malformed input.

## Highlights

- Encode 5 to 6 ms vs Python msgpack (C ext) 33 to 34 ms on 100,000 records (4.86 MB); decode x5 110 to 119 ms vs 308 to 320 ms; peak RSS 81 MB vs 139 MB.
- Every malformed input raises with the byte named: truncation, overrunning lengths (nothing allocated), invalid UTF-8, `0xc1`, trailing bytes, nesting past 1024.

## Known limits

- Not covered by the oracle: extension codes below -1 (one checked in `tests/api.mojo`) and lengths above 2^32-1 on encode.
- Mojo 1.2 only.
